# Corrida Lunar

Jogo 2D desenvolvido em Python com Pygame.

## Requisitos

- **Python 3.10.0 (64-bit)**

## Bibliotecas necessárias

- **pygame** (`2.6.1` ou compatível)

Para instalar a biblioteca usando o Python 3.10:

```powershell
py -3.10 -m pip install pygame
```

*(Os demais módulos utilizados — `os`, `sys`, `random` e `math` — já fazem parte da biblioteca padrão do Python.)*

## Como rodar o jogo

1. Certifique-se de que o interpretador selecionado no editor é o **Python 3.10.0 (64-bit)**.
2. Abra o arquivo **`main.py`**.
3. Clique no ícone de **Play (▶)** no canto superior direito para executar o código.

*(Se preferir rodar pelo terminal, execute `py -3.10 main.py`.)*

## Controles

- **A / D** ou **Setas (Esquerda / Direita):** Mover
- **ESPAÇO** ou **Seta para Cima:** Pular
- **S** ou **Seta para Baixo:** Agachar
- **ENTER:** Iniciar / Jogar novamente
- **ESC:** Sair do jogo
